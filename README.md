ApexPlanet Software Pvt. Ltd. — 60-Day Data Analytics Internship

Welcome to my Data Analyst Internship Portfolio.

This repository brings together my work completed during the 60-Day Data Analytics Internship at ApexPlanet Software Pvt. Ltd. It serves as a single reference point for the projects, analysis, dashboards, and learning outcomes developed throughout the internship.

The internship followed an end-to-end data analytics workflow — from data cleaning and preparation to exploratory analysis, business intelligence, customer segmentation, dashboarding, and data storytelling.
